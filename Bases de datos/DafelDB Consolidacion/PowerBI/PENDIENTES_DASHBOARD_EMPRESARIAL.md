# Pendientes para una versión empresarial

El PBIX actual está completo para la entrega académica: contiene las consultas solicitadas, una página gerencial, páginas de detalle, datos de demostración, relaciones y medidas. Para convertirlo en un tablero productivo de uso continuo todavía conviene completar lo siguiente:

1. **Datos reales y metas**. Sustituir o separar los registros ficticios e incorporar metas mensuales de conversión, utilización, recaudo y cartera.
2. **Actualización automática**. Publicar en Power BI Service, configurar el gateway para SQL Server y definir una frecuencia de actualización.
3. **Indicador de vigencia**. Mostrar la fecha y hora de la última actualización en todas las páginas.
4. **Filtros sincronizados**. Sincronizar periodo, cliente y ciudad entre las cuatro páginas para mantener el mismo contexto de análisis.
5. **Cartera por antigüedad**. Agregar rangos de vencimiento (vigente, 1-30, 31-60, 61-90 y más de 90 días) y alertas visuales.
6. **Metas y semáforos**. Comparar cada KPI contra un objetivo aprobado por Dafel; no inventar umbrales empresariales sin validación del dueño.
7. **Detalle navegable**. Crear páginas de drill-through para cliente, alquiler y recurso, además de tooltips enriquecidos.
8. **Seguridad**. Definir seguridad por filas si empleados o clientes deben consultar únicamente información autorizada.
9. **Accesibilidad y móvil**. Revisar contraste, texto alternativo, orden de tabulación y diseño para teléfono.
10. **Gobierno del dato**. Documentar responsables, reglas de calidad, tratamiento de datos personales y procedimiento de respaldo.

Ninguno de estos puntos impide presentar el archivo actual. Son mejoras posteriores para operación real, publicación y mantenimiento.
